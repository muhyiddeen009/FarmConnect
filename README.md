# FarmConnect

A responsive first version of FarmConnect: a welcoming website connecting local farmers and buyers. The marketplace is powered by sample produce listings, with working category filters, search, mobile navigation, saved-item toggles, and email enquiry links.

## Run locally

Requirements: Node.js 18.17 or newer.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- This is a frontend-first MVP; listings and prices are sample content, not live market data.
- Contact and enquiry actions open an email draft to `hello@farmconnect.ke`; replace this with the project's real contact address before launch.
- Product and hero photography currently loads from Unsplash.
